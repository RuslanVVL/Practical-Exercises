МОДУЛЬНЫЕ ТЕСТЫ КАЛЬКУЛЯТОРА НА C++

Состав проекта:
- Calc.h       объявления функций и переменной памяти;
- Calc.cpp     реализация функций калькулятора;
- main.cpp     консольное меню приложения;
- CalcTests.cpp модульные тесты.

Требуется компилятор C++ с поддержкой C++17 (например, g++).
Сторонние библиотеки не нужны.

Сборка приложения:
g++ -std=c++17 Calc.cpp main.cpp -o CalcApp
Запуск:
./CalcApp

Сборка и запуск тестов:
g++ -std=c++17 Calc.cpp CalcTests.cpp -o CalcTests
./CalcTests
